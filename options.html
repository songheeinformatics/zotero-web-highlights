Web Highlights for Zotero

드래그한 문장 + 메모 → 그 페이지의 Zotero 아이템에 노트 하나로 모아 저장

1. Zotero API 키

  1. zotero.org/settings/keys/new에서 새 키 만들기
  2. Allow library access, Allow notes access, Allow write access 모두 체크 (그룹에 저장하려면 그룹 쓰기 권한도)
  3. 발급된 키를 아래에 붙여넣고 연결 확인

2. 저장 위치

사용법

  1. 웹페이지에서 문장을 드래그하면 빨간 Z 버튼이 뜹니다. 누르거나 Alt+Z.
  2. 메모를 쓰고 저장 (Ctrl+Enter).
  3. 같은 페이지에서 다시 긁으면 같은 노트 아래에 계속 이어붙습니다.
  4. 페이지에 해당하는 아이템이 라이브러리에 없으면 서지(웹페이지 또는 DOI가 있으면 학술논문)를 새로 만듭니다. 이미 Zotero Connector로 저장한 아이템이 있으면 URL/DOI로 찾아 그 아래에 붙입니다.

API 키는 이 브라우저의 로컬 저장소에만 보관되며, 요청은 api.zotero.org로만 전송됩니다. 개발자나 제3자 서버로는 아무것도 전송되지 않습니다.
